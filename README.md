# DDD Final Project

這是軟體工程課程的 Final Project，目標是使用 Domain-Driven Design（DDD）風格完成一個 software engineering project。

## Project Goal

本專案將包含：

1. 需求分析
2. 系統設計
3. DDD 領域建模
4. Mermaid UML 圖
5. AI 開發紀錄與提示詞
6. 程式實作
7. AI 開發效益評估
